# VYBE Frontend

A modern entertainment discovery and booking frontend built with React, Vite, Tailwind CSS, React Router, Framer Motion, React Hook Form, and Lucide React.

## Run locally

```bash
npm install
npm run dev
```

Then open the local Vite URL shown in the terminal.

## Notes

- Frontend only.
- No APIs or backend are connected.
- All movies/events/bookings use local mock data.
- API integration can be added later under `src/services/`.
